# Agent contract

This repository is an Agent-first research feed, not an autonomous trading system. Keep collection deterministic and auditable: every content item must carry a stable ID, original URL, source timestamp, collection timestamp, and source type. A pipeline failure must be visible in feed metadata and must not erase healthy pipeline output.

When generating a report, use the selected profile and prepared context. Separate sourced facts from inference, retain links, use only collected market-price fields, and state missing evidence. Investment ideas must include a transmission mechanism and falsification condition; popularity alone is not an investment thesis.
